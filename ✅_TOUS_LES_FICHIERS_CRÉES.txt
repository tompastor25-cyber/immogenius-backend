🚀 POUR COMMENCER (ULTRA RAPIDE)
════════════════════════════════════════════════════════════════════════════

Étape 1: Installer
   $ npm install

Étape 2: Configurer PostgreSQL
   $ createdb immogenius

Étape 3: Variables d'environnement
   $ cp .env.example .env
   (Éditer .env avec DATABASE_URL et JWT_SECRET)

Étape 4: Créer les tables
   $ npx prisma db push
   $ node scripts/setupDb.js

Étape 5: Lancer le serveur
   $ npm start

Étape 6: Ouvrir
   http://localhost:3000

Étape 7: Se connecter
   Email: agent@immobilier.fr
   Mot de passe: password123

✅ VOILÀ! Vous avez un SaaS complet!
