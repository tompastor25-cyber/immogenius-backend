🎓 STRUCTURE SIMPLE À COMPRENDRE
═══════════════════════════════════════════════════════════════════════════════

User (Browser)
    ↓
index.html / auth.html / features.html ... (Pages HTML)
    ↓ (JavaScript appelle l'API)
fetch('/api/auth/login')
    ↓
server.js (Express)
    ↓ (Route → Service → Base de données)
src/routes/auth.js → src/utils/jwt.js → Prisma → PostgreSQL
    ↓ (Réponse JSON)
Response: { success: true, token: "..." }
    ↓ (JavaScript sauvegarde le token)
localStorage.setItem('token', '...')
    ↓
User est connecté!

C'est aussi simple que ça!
