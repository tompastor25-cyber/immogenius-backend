═══════════════════════════════════════════════════════════════════════════════
                         FLUX DE DONNÉES PRINCIPAL
═══════════════════════════════════════════════════════════════════════════════

1. AUTHENTIFICATION
   User submits email/password
        ↓
   server.js validates input
        ↓
   src/routes/auth.js processes signup/login
        ↓
   bcryptjs hashes password
        ↓
   Prisma saves to PostgreSQL
        ↓
   src/utils/jwt.js generates token
        ↓
   Token returned to client

2. GÉNÉRATION IA
   User submits property details
        ↓
   server.js checks JWT authentication
        ↓
   src/routes/content.js receives request
        ↓
   Rate limiter checks limit (10/hour)
        ↓
   src/services/openai.js calls OpenAI API
        ↓
   Generated content returned
        ↓
   Prisma saves to generated_content table
        ↓
   Result returned to client

3. PAIEMENT
   User clicks "Subscribe"
        ↓
   src/routes/payment.js creates checkout session
        ↓
   Stripe.createCheckoutSession() returns URL
        ↓
   User redirected to Stripe
        ↓
   User completes payment
        ↓
   Stripe webhook calls /api/payment/webhook
        ↓
   src/services/stripe.js handles webhook
        ↓
   Prisma updates user subscription
        ↓
   User granted access to premium features

═══════════════════════════════════════════════════════════════════════════════
                         FLUX D'UTILISATION TYPIQUE
═══════════════════════════════════════════════════════════════════════════════

1. UTILISATEUR NOUVEAU
   ├─ Visite http://localhost:3000
   ├─ Clique sur "Essayer gratuitement"
   ├─ Remplit le formulaire d'inscription (auth.html)
   ├─ POST /api/auth/signup
   ├─ Reçoit un JWT token
   ├─ Redirigé vers le dashboard (page d'accueil)
   └─ Trial de 7 jours activé

2. UTILISATION
   ├─ Remplir les détails du bien
   ├─ Cliquer "Générer l'annonce"
   ├─ POST /api/content/generate-listing
   ├─ OpenAI génère le contenu
   ├─ Affichage du résultat
   ├─ Historique sauvegardé en BD
   └─ Compteur de générations incrémenté

3. PAIEMENT
   ├─ Trial expire (7 jours)
   ├─ Voir page pricing
   ├─ Cliquer "Commencer"
   ├─ POST /api/payment/create-checkout-session
   ├─ Redirection vers Stripe Checkout
   ├─ Paiement complété
   ├─ Webhook reçu (Stripe → server)
   ├─ Abonnement activé en BD
   └─ Accès complet déverrouillé

4. GESTION DU COMPTE
   ├─ Voir le profil
   ├─ Voir l'historique
   ├─ Voir les factures
   ├─ Annuler l'abonnement
   └─ Se déconnecter
