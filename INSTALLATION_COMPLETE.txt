🚀 DÉMARRAGE RAPIDE (5 MINUTES)

1️⃣ INSTALLER LES DÉPENDANCES
   $ npm install

2️⃣ CONFIGURER POSTGRESQL
   Option A - Local:
   $ createdb immogenius

   Option B - Docker:
   $ docker run --name postgres-immo \
     -e POSTGRES_DB=immogenius \
     -e POSTGRES_PASSWORD=password123 \
     -p 5432:5432 -d postgres:15

3️⃣ CRÉER LE FICHIER .ENV
   $ cp .env.example .env

   Éditer .env avec:
   DATABASE_URL="postgresql://postgres:password123@localhost:5432/immogenius"
   JWT_SECRET="votre-clé-secrète-de-minimum-32-caractères"

4️⃣ CRÉER LES TABLES
   $ npx prisma db push
   $ node scripts/setupDb.js

5️⃣ LANCER LE SERVEUR
   $ npm start

   Ouvrir: http://localhost:3000

6️⃣ SE CONNECTER
   Email: agent@immobilier.fr
   Mot de passe: password123

🔑 INTÉGRATIONS EXTERNES REQUISES

Pour la génération IA (OpenAI):
   1. Créer un compte: https://platform.openai.com
   2. Créer une clé API
   3. Ajouter à .env: OPENAI_API_KEY=sk-...
   4. Ajouter du crédit: https://platform.openai.com/account/billing

Pour les paiements (Stripe):
   1. Créer un compte: https://stripe.com
   2. Créer les clés API (test/production)
   3. Ajouter à .env: STRIPE_SECRET_KEY=sk_test_...
   4. Configurer les webhooks (voir DEPLOYMENT.md)

🧪 TESTER L'API

Health check:
   $ curl http://localhost:3000/api/health

S'inscrire:
   $ curl -X POST http://localhost:3000/api/auth/signup \
     -H "Content-Type: application/json" \
     -d '{"email":"test@example.com","password":"password123","name":"Test","structure":"independent"}'

Se connecter:
   $ curl -X POST http://localhost:3000/api/auth/login \
     -H "Content-Type: application/json" \
     -d '{"email":"agent@immobilier.fr","password":"password123"}'

Générer une annonce (remplacer TOKEN):
   $ curl -X POST http://localhost:3000/api/content/generate-listing \
     -H "Authorization: Bearer TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"address":"Paris","surface":85,"rooms":3,"type":"apartment","condition":"excellent"}'
